## Narration N0: spike, measure Kokoro-82M on this PC (2026-10-07)

Spec: [`specs/2026-10-07-kokoro-narration.md`](../specs/2026-10-07-kokoro-narration.md) ·
ADR: [`adr/0001-tts-engine-kokoro-onnx.md`](../adr/0001-tts-engine-kokoro-onnx.md) ·
Numbers: [`performance.md`](../performance.md) (Kokoro section)

**Problem.** Before building the narration UI, we need to know whether Kokoro-82M can
speak fast enough on this CPU (the GPU is reserved for Whisper) and which model variant
and settings to use.

**Change.**

- `app/requirements.txt`: added `kokoro-onnx>=0.6.1,<0.7` (installs onnxruntime 1.30.0,
  espeakng-loader 0.2.4, phonemizer 3.4.0; numpy 2.5.3 stays as it is).
- `tools/tts_bench.py` (new): variant × threads table (load, warm-up, first sentence,
  RTF), `--first-chunks` (2/5/8/16-word prefixes), `--samples` (one WAV per language),
  `--offline` (blocks Python networking), `--no-bench`.
- `.gitignore`: `/models/` now has its own comment (it holds `models/kokoro/`).
- Model files downloaded to `models/kokoro/`, and the sha256 of all three downloads
  (fp32, int8, voices) matches the release. The 7 language samples are in
  `models/kokoro/samples/` (gitignored).
- Docs: `performance.md` (new Kokoro section), ADR 0001 → **Accepted** (one check still
  open, see below), spec (fp32, 4 threads, 6-word first-chunk cap, `MAX_CHARS` 120,
  decision 4 resolved), test plan (first-chunk cases; es/fr added to T-TTS-2),
  `current-state.md` (narration setup steps, next task N1).
- No app code changed, so app behavior is unchanged.

**Results** (CPU only, i5-10400F, idle CPU, fp32 with 4 threads unless noted)

| Finding | Number | Target |
|---|---|---|
| RTF total | **0.36 / 0.40** (two runs) | ≤ 0.5 ✅ |
| int8 | RTF 4.54, ~10× slower than fp32 → rejected | — |
| First sound, 16-word first sentence | 1.80 s p50 | ≤ 1.0 s ❌ |
| First sound, 5-word first chunk | **0.84 / 0.73 s** p50, max 0.91 s | ≤ 1.0 / 1.5 s ✅ → 6-word cap in spec §5.2 |
| Same 5-word chunk under CPU contention (background indexing job) | 1.33 s p50 | ⚠ re-measure with Dictation running in N5 |
| Load + warm-up | 1.3–1.5 s + ~2.0 s (in the background) | ≤ 5 s ✅ |
| Offline | runs with all Python socket calls blocked | ✅ |
| Languages | en-us, en-gb, es, fr-fr, hi, it, pt-br produce non-silent audio | ⏳ intelligibility: the user listens to the samples |
